# Changelog

## v1.0.0 - 2026-09-06

### Added
- 添加 Intel `IA32_PERF_STATUS` 内核驱动和受限的只读频率查询 IOCTL。
- 添加支持 Processor Group 的用户态持续采样 CLI。
- 添加管理员安装、卸载脚本及独立版本化发布目录规范。

### Changed
- 放弃在当前硬件上始终返回固定 3600 MHz 的 PerfLib 实现，主分支转为驱动架构。

### Notes
- 驱动加载需要 Windows 可接受的数字签名；开发阶段实机验证需要测试签名环境。

## v1.1.0 - 2026-09-06

### Added
- 添加对 PawnIO 官方签名驱动和 `IntelMSR.bin` 0.2.11 模块的直接调用。
- 添加 `--once` 一次性采样模式。

### Changed
- 主频读取后端由自有未签名驱动改为 PawnIO，不再要求 Windows 测试模式。
- 应用启动时请求管理员权限，以符合 PawnIO 的设备访问策略。

### Removed
- 移除无法在普通 Windows 签名策略下加载的自有 `.sys` 驱动及其安装脚本。

### Notes
- PawnIO 2.2.0 的系统驱动已在测试机验证为 Microsoft Windows Hardware Compatibility Publisher 签名。

## v1.1.1 - 2026-09-06

### Fixed
- 严格区分模块文件大小查询失败与无效大小，避免返回陈旧的 Win32 错误码。

### Notes
- 最终管理员实机测试读取到 P 核逻辑线程 5000 MHz、E 核逻辑线程 4000 MHz。

## v1.2.0 - 2026-09-06

### Added
- 添加原生圆角浮窗、逐逻辑核心总占用/内核占用叠加条、GHz 频率和最高有效核心温度。
- 添加托盘菜单、设置窗口、全窗拖动、双击隐藏和超高浮窗滚轮查看。
- 添加透明度、宽度、字体、行距、条高、内边距、圆角、刷新间隔与置顶设置，自动保存设置和位置。
- 添加命名互斥量与窗口消息单实例 IPC，重复启动唤醒已有浮窗后退出。
- 添加模拟预览、独立 UI 自检及真实传感器诊断模式。

### Changed
- 默认启动进入图形界面，使用 Direct2D / DirectWrite 和按文字测量计算的 DPI 自适应布局。
- 保留 --once 频率采样入口；UI 采样在后台线程执行。

### Notes
- P/E/SuperP 核心识别留待下一阶段。
- 实机 20 个逻辑核心的频率、总占用、内核占用和温度读取通过；截图验收受当前 Windows 捕获接口限制。

## v1.3.0 - 2026-09-06

### Added
- 添加 English / 简体中文语言设置，即时切换设置、托盘右键菜单、关于和状态文本，并保存语言选择。
- 添加 CPU 使用率口径选择，保留时间占用率供用户选择。

### Fixed
- 默认使用 Processor Utility / Privileged Utility 配对计数器，修正与 Windows 10 任务管理器使用不同统计口径导致的进度条差异。
- 对睿频时超过 100% 的性能使用率限制显示上限，内核段使用相同刻度且不超过总长度。

### Notes
- 版本升级保留已有 UI 参数；未设置语言时按系统 UI 语言选择中文或英文。
- 中英文菜单与设置切换、语言配置读写和 Core3 固定负载采样验证通过。

## v1.4.0 - 2026-09-07

### Added
- 添加基于 Windows 拓扑与逐逻辑核 CPUID 的物理核心、P/E 类型、SMT sibling、x2APIC 和 PMU 静态能力识别。
- 添加 P 核物理分组与最多 6 个 E 核一组的布局，显示占用百分比、核心温度和 IPC 不可用状态。
- 添加 Alder Lake Package 温度、RAPL 差分功率和基于官方签名 IntelMCHBAR 模块的真实 DRAM 读写带宽。
- 添加仅作用于 Busy / 温度指标本身的橙红色异常提示、EMA、持续时间、滞回和暂停恢复处理。
- 添加硬件差分/拓扑回归测试与有限时长 CPU、内存、采样和刷新延迟测量入口。

### Changed
- 默认恢复 Busy Time / Processor Time，Utility 只保留为手动选项；新版本默认约 4 Hz。
- 缓存拓扑、TjMax、RAPL 单位和可用 IMC bank；温度按物理核心采样，避免 SMT 重复读取。
- PawnIO 请求使用栈缓冲，画刷和数据容器复用，窗口刷新通知合并，等待时间扣除采样耗时。
- CPU 名称换行、窗口宽度按屏幕约束计算，过高分组继续使用滚轮查看。

### Notes
- IPC、LLC Miss/Reference/MPKI 仍不可用：官方 IntelMSR 0.2.11 未开放所需 PMU 计数器和控制寄存器，实机能力探测返回 ERROR_ACCESS_DENIED；未生成替代估算值。
- 传感器 profile 当前只对 Alder Lake 97h/9Ah 启用，其他架构保留拓扑与 PDH，后续需逐平台验证。
- 有限时长负载测量约占整机 CPU 0.051%、工作集 44.1 MiB；完整测量口径及截图接口限制见 TEST_RESULTS.md。


## v1.5.0 - 2026-09-07

### Added
- 设置和托盘右键增加详细/精简模式；精简模式恢复 CoreN 横条与频率、底部温度布局。
- 设置增加小号/默认尺寸预设与「显示内容」选项卡，可独立选择 IPC、RAM R/W、LLC MPKI、频率、温度及详细模式功耗。
- 随发行包提供校验哈希/签名的官方 PawnIO 2.2.0 安装器与重装脚本；本机已使用项目内安装包完成重装。

### Changed
- 浮窗固定英文，设置和托盘仍支持英文/简体中文；标题简化为厂商与型号。
- 刷新率改为可设置的 1–10 Hz，默认 4 Hz；P 核子条零间隔，布局高度按当前模式和内容计算。
- RAM R/W 默认显示 GB/s 数值；关闭显示时停止 IMC 采样，重新开启时重建基线。

### Removed
- 删除 RAM 带宽固定 100 GB/s 上限与比例条，避免把显示标尺误当作硬件带宽上限。

### Notes
- IPC / LLC MPKI 默认隐藏，当前签名模块不可读取时显示 N/A。
- 回归自检与重装后实机读取通过；默认模式 20 秒测量约整机 CPU 0.020%、工作集 44.10 MiB，详见 TEST_RESULTS.md。
- PawnIO 是系统共享内核驱动，随附安装包不代表创建项目私有驱动实例。

- 新增按需启停、独占会话所有权、遗留会话恢复、错误降级、过期数据失效和退避重试。

### Notes
- 实机、权限降级、会话竞争、开关/恢复及异常退出恢复测试通过，用户确认 v1.6.1 视觉检查 OK。
- 开启 ETW 的本轮 20 秒测量约占整机 CPU 0.136%，工作集 44.65 MiB；完整口径和未现场验证的场景见 TEST_RESULTS.md。
- 本版按用户指定版本 1.6.1 发布；此前 1.6.0 构建仅用于开发验证，未创建 1.6.0 发布目录。

## v1.7.0 - 2026-10-06

### Added
- 新增进阶模式：详细主浮窗之外显示独立 P 核 TMA 面板，包含四类顶层比例、Core/Memory Bound，位置独立保存，跟随透明度、置顶及字号设置。
- TMA 与 IPC/LLC 共用 ETW 会话；采用临时自定义事件注册，注册失败回退普通 PMU，保留退避重试、失效及资源清理。
- 新增“很小”预设，采用用户提供的 250 DIP 宽度、9 DIP 字号、6 DIP 条高、1 Hz 等参数。

### Changed
- 精简模式按物理核心合并 P 0/E 8 等名称和频率，SMT 占用条贴合居中，IPC 分开；P 核每条增加约 5 个实际像素，限于原来的核心行组高度。
- 统一托盘/关于版本显示为 1.7.0，TMA 大字号超高面板支持滚轮查看。

### Notes
- Bad Speculation 依用户要求显示原始值并标注未验证，Frontend/Core 为估算；L1/L2/L3/DRAM 尚未采集，显示 N/A。
- 本机新版 WPT WPR 注册及 TMA/IPC/LLC 同时采集、模式生命周期、权限降级和 UI 回归通过；用户确认最终精简条高合适，可以打包。
- TMA 是 P 核整体活动统计，当前仅 i7-12700KF 实机验证，不代表事件比例精度认证；没有新增驱动或签名申请。


## v1.8.0 - 2026-10-13

### Added
- 进阶 TMA 的 Memory 区域接入 P 核 L1/L2/L3/DRAM Bound，使用 Intel 原始事件及周期公式，显示四项百分比与数据年龄。

### Changed
- ETW 计数器分两组每 5 秒轮换，保留 IPC/LLC 采集；槽位与周期口径明确区分，TMA 数据超过 12 秒失效，IPC/MPKI 超过 2 秒失效。
- 随附注册 profile 增加四个非持久内存停顿事件；发布版本统一为 1.8.0。

### Fixed
- 调整受限 stall 事件的 PMC 分配顺序，修复本机 L1/L2 计数为零的问题。
- 零周期空闲样本不再误清空另一计数器组；轮换保持 owner 锁，错误、重置和关闭时清空旧值。

### Notes
- i7-12700KF / Windows 10 19045 实机负载、轮换、有无 LLC、冲突、权限降级、资源清理及 UI 回归通过；人工视觉检查已发起，尚待反馈。
- 四项以 P 核周期为分母，不是缓存命中率，也不是上方 Memory Bound 的内部百分比分解。Bad Speculation 仍未验证。
- 使用既有 ETW/WPT，无新增驱动、签名申请或环境安装；其他硬件及 Windows 版本仍需验证。
